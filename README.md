# Phitron CSE Fundamentals

This repository is a personal, Git-friendly study and code workspace for the Phitron CS Fundamentals / Programming Journey, October 2026 intake. It is organized across Semester 1 through Semester 3 and is designed to adapt to the modules released for the actual batch.

## Semester Structure

- `01_SEMESTER_1`: programming foundations, early problem solving, and C++ preparation.
- `02_SEMESTER_2`: data structures, algorithms, and continued problem solving.
- `03_SEMESTER_3`: flexible competitive-programming and software-development tracks. Rename containers to match the actual dashboard when needed.

## Folder Organization

Each course has `Modules`, `Assessments`, `Practice`, `Conceptual_Sessions`, `Revision`, `Cheat_Sheets`, and `Resources`. `04_PROBLEM_SOLVING` stores selected reference problems independently; it does not duplicate module work automatically. Global contests, exams, revision, resources, achievements, and trackers are kept at the repository root.

## Modules

Modules are intentionally created only when released. Copy `_TEMPLATES/MODULE_TEMPLATE` with `tools/new-module.ps1`. Module folder names use `Module_01_Basic_Syntax` and also support fractional identifiers such as `Module_02.5_Practice_Day_01`.

## Assessments and Contests

Use `06_EXAMS` for exam records and `_TEMPLATES/EXAM_TEMPLATE` for individual exams. Use `05_CONTESTS` and `_TEMPLATES/CONTEST_TEMPLATE` for contest notes, solutions, and upsolving.

## Progress Tracking

Open `STUDY_DASHBOARD.md` daily, summarize course progress in `COURSE_PROGRESS.md`, and record results in the root CSV trackers. Record recurring mistakes in `07_REVISION/Mistake_Notebook/mistakes.md`.

## Naming Conventions

- Semester: `01_SEMESTER_1`
- Course: `01_INTRODUCTION_TO_C_PROGRAMMING`
- Module: `Module_01_Basic_Syntax` or `Module_02.5_Practice_Day_01`
- Exam: `Weekly_Exam_01`, `Midterm_Exam`, `Final_Exam`
- Contest: `2026-10-10_Phitron_Contest_01`
- Problem: `001_Problem_Name.c` or `002_Problem_Name.cpp`
- Notes: `notes.md`

## Recommended Daily Workflow

1. Check `STUDY_DASHBOARD.md`
2. Open current module
3. Watch lesson
4. Write notes
5. Save class code
6. Solve practice problems myself
7. Attempt quiz
8. Log mistakes
9. Update problem-solving log
10. Update module status
11. Revise weak topics
12. Commit progress to Git

## Academic Integrity

For assignments, quizzes, exams, and contests, attempt problems independently first. AI-generated solutions should not be used to bypass Phitron assessment rules. AI can be used afterward for explanation, debugging, alternative approaches, and revision where allowed.
